# CRM AMZ — application iPhone / iPad

Application de relances patients du centre Idéal Audition Orléans.

Ce dépôt contient **uniquement le programme** (aucune donnée patient).
Les données restent sur chaque appareil et passent d'un appareil à l'autre
par un fichier chiffré (Réglages › iPhone, iPad et ordinateur).

Adresse : https://zey770.github.io/crm-amz/
